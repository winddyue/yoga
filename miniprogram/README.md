# 小程序脚手架（微信小程序原生）

> **状态：脚手架。** 页面与 API 对接已打通骨架，样式与业务细节待正式开发时完善。

## 对应后端

FastAPI 后端（`../backend`），JWT 登录态与 Web 管理端复用同一套 `/api/*` 接口。

## 在微信开发者工具中导入预览

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 新建项目 → 项目目录选择本目录（`miniprogram/`）。
3. 填入你的小程序 **AppID**（体验版/真机预览需要；仅本地调试可用测试号）。
4. 后端地址：修改 `api.js` 顶部的 `BASE` 为你的后端地址。
   - 本地调试：后端跑在 `http://127.0.0.1:8000`，需在开发者工具中勾选
     「详情 → 本地设置 → 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
   - 生产环境：必须使用 **HTTPS** 域名，并在小程序后台「开发管理 → 开发设置 → 服务器域名」中配置 request 合法域名；域名需完成 **ICP 备案**。
5. 点击「编译」即可预览；「预览」可扫码在手机上体验。

## 页面

| 页面 | 说明 |
|---|---|
| pages/login | 账号密码登录 + **微信一键登录**（wx.login 免密）；密码登录后自动绑定微信 |
| pages/index | 首页：按角色展示（客户看进展/教练看工作台概览/馆主看全馆），带加载/空态/错误重试 |
| pages/booking | 约课：课程列表、预约/取消（满员自动候补）、**扫码签到**、我的预约状态展示 |
| pages/training | 我的训练/饮食：训练计划与饮食方案 |
| pages/coach | 教练工作台：**出示签到二维码**、课程名单、手动补签（不受时间窗限制） |
| pages/mine | 我的：个人信息、退出登录（带确认） |

## 本轮新增能力

1. **微信免密登录**：`wx.login` code → 后端 `/api/auth/wx-login` 换 JWT。
   首次用账号密码登录时自动绑定（`/api/auth/wx-bind`），之后可一键登录。
   后端需配置 `WX_APPID`/`WX_SECRET`；本地/CI 可设 `WX_DEV_MOCK=true`
   用 `"mock:任意标识"` 作 code 联调（生产禁止）。
2. **扫码签到（带时间窗）**：二维码内容约定为 `yoga:checkin:课程id:签到码`。
   教练在工作台点「签到码」实时生成出示；客户在约课页扫码签到。
   客户自助签到仅允许**开课前 30 分钟 ~ 开课后 60 分钟**（`CHECKIN_OPEN_MIN` /
   `CHECKIN_CLOSE_MIN` 可配），教练可随时手动补签。
3. **统一交互反馈**（`utils/feedback.js`）：加载中/成功/失败/空态/确认弹窗全覆盖，
   网络断开与超时有明确中文提示，杜绝"显示成功但服务端无记录"的误导；
   401 统一清 token 跳登录页。
