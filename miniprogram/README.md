# 小程序脚手架（微信小程序原生）

> **状态：脚手架。** 页面与 API 对接已打通骨架，样式与业务细节待正式开发时完善。

## 对应后端

FastAPI 后端（`../backend`），JWT 登录态与 Web 管理端复用同一套 `/api/*` 接口。

## 在微信开发者工具中导入预览

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 新建项目 → 项目目录选择本目录（`miniprogram/`）。
3. 填入你的小程序 **AppID**（体验版/真机预览需要；仅本地调试可用测试号）。
4. 后端地址：修改 `api.js` 顶部的 `BASE` 为你的后端地址。
   - 本地调试：后端跑在 `http://127.0.0.1:8000`，需在开发者工具中勾选
     「详情 → 本地设置 → 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
   - 生产环境：必须使用 **HTTPS** 域名，并在小程序后台「开发管理 → 开发设置 → 服务器域名」中配置 request 合法域名；域名需完成 **ICP 备案**。
5. 点击「编译」即可预览；「预览」可扫码在手机上体验。

## 页面

| 页面 | 说明 |
|---|---|
| pages/login | 用户名+密码登录，token 存本地 |
| pages/index | 客户首页：我的进展（目标/出勤率/体重变化/待上课程） |
| pages/booking | 约课：课程列表、预约/取消、扫码签到 |
| pages/training | 我的训练/饮食：训练计划与饮食方案 |
| pages/coach | 教练工作台：课程名单、签到确认（入口由教练角色可见） |
| pages/mine | 我的：个人信息、AI 订阅状态、退出登录 |

## 上架前合规事项（提醒）

- 小程序类目选择健身相关类目并完成 ICP 备案。
- 收集 AI 订阅费用需开通微信支付商户号；iOS 端小程序内虚拟商品支付受限，定价策略需单独考虑。
- 隐私政策与用户协议见 `../docs/`，上架时按微信要求在小程序内展示。
