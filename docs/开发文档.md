## 2. 功能设定（Dylan 需求）

### 2.1 账号与登录
- 微信登录：`wx.login code → code2session → openid → 系统 JWT`
- 账号密码绑定微信、一键登录、自助建档、手机号登录（`getPhoneNumber`）
- `WX_DEV_MOCK` 仅本地开发使用，生产环境强制关闭

### 2.2 健康管理（核心）
- **15 字段体测表单**：身体成分（身高/体重/体脂/肌肉量/BMI/内脏脂肪）、围度（胸/腰/臀/上臂/大腿）、健康指标（静息心率/血压/伤病史/备注）；BMI 按身高体重自动计算；提交后展示"本次 vs 上次"对比卡
- **身体趋势图**：体重/体脂/腰围三指标切换，"较上次"变化 chip
- **健康仪表盘**：出勤率圆环、本月体测次数、距上次评估天数、进行中计划数、本月总结（一句话 + 关键数字）
- **自定义字段**：馆主可增删 `target=assessment` 的 text/number 字段；客户自助、教练代录、表单动态渲染；字段删除后历史数据保留并标注"已删除字段"
- **合规**：敏感身体数据单独授权（PIPL）；未满 14 岁需监护人同意；隐私政策/用户协议上线前需法务审核

### 2.3 训练计划
- 按客户目标自动生成一周计划（减脂/增肌/塑形模板，可扩展为 LLM）
- 教练可编辑；**动作库 36 个**（瑜伽 16/力量 14/有氧 3/拉伸 3），计划页支持搜索、分类、点选回填
- **计划详情页**（客户）：按天展示动作与组数×次数，当天自动高亮，底部"今日训练打卡"快捷入口
- **计划获取**（空状态不再干等）：AI 生成训练计划 / 请求教练制定（一键通知教练）/ 教练建好后推送通知客户

### 2.4 饮食方案
- **营养公式**（v9，参考 Fud AI 思路）：Mifflin BMR → TDEE（×1.375）→ 减脂 −400kcal / 增肌 +250kcal；蛋白质 2.0/1.8/1.6 g/kg、脂肪占总热量 25%、碳水补齐；AI 配餐前先算目标，把热量和三大营养素作为硬约束喂给 LLM
- **双轨制**：快轨 AI 秒出 `ai_draft`（标"AI 生成·待教练确认"+免责声明）→ 准轨教练微调后一键确认
- 未配置真实 LLM 时返回 503，不静默降级
- 客户点饮食卡片展开四餐明细 + 宏量

### 2.5 打卡（执行闭环）
- 每日训练打卡 / 饮食打卡：直接打卡或**拍照打卡**（拍张照上传算数）
- 每天每种限一次；本月打卡天数统计 + 最近记录；已打卡按钮置灰 ✓
- 教练在客户详情"打卡记录"区查看，点 📷 放大看照片
- 照片走鉴权下载（`/api/files`），不做公开静态挂载（隐私设计）

### 2.6 智能录入
- 文字录入 / 拍照 OCR，AI 提取体测字段，**人工确认后**写入
- 未配置 OCR/ASR 时返回 403/501，不静默降级
- （规划）右上角 ➕ 快捷入口：智能录入/添加字段/记录体测等——方案已定，待排期

### 2.7 AI 会员订阅（v11/v12，微信支付）
- 学员付订阅费给馆主，解锁 AI 功能（AI 生成训练计划、AI 饮食方案等）
- 套餐：月卡/季卡/年卡（种子占位价 ¥29/79/299）；**价格/时长/上下架由馆主在小程序"订阅套餐管理"页自定**，已售订单不受改价影响
- 支付成功回调自动开通/续期（有效期内续费顺延）；无订阅调 AI 接口返回 **402 "开通 AI 会员后使用"**，小程序弹窗引导开通
- 教练手动开通通道保留；staff 调用不受门禁影响

### 2.8 通知
- 站内通知：AI 初版、教练确认、预约成功、候补转正、签到、订单支付成功
- 微信订阅消息：模板申请中（一次性订阅机制，一次授权发一条）

### 2.9 约课（已隐藏，未删除）
- 课程发布/预约/候补/签到码/名单补签代码保留；C 端入口与教练工作台课程区已隐藏，待 Dylan 决定恢复

### 2.10 主题与体验
- 12 套主题，默认 A 山茶绿（Dylan 偏好明亮清新）
- 主题切换持久化：storage → 内存 → 默认三级 fallback，写后读回校验，23+ 页面统一 `syncTheme`
- Dylan 要求"越简单越好"：结果优先、限制如实说明、不懂的给选项

## 3. 系统架构

```
微信小程序（原生，27 页面）
        │ HTTPS
        ▼
FastAPI 后端（api.zytzml.cn）
  ├─ SQLAlchemy ORM
  ├─ SQLite（默认）/ Postgres（增长路径，DATABASE_URL 切换）
  └─ Alembic 迁移（0001→0005）
```

- **后端**：Python FastAPI，JWT 认证，RBAC（client/coach/owner）
- **小程序**：微信原生小程序，3 个 tab（首页/训练/我的）
- **AI**：BYOK 模式——馆主配置 LLM key 后启用；`ai_gate` 统一门禁（门店级订阅 + 学员订阅 + 用量计量）
- **支付**：微信支付 v3（JSAPI），馆主商户号
- **部署**：腾讯云 2核4G（43.128.26.65），Docker + nginx + certbot，`deploy/` 一键脚本

### 时区规范（重要）
- 入库时间统一 UTC（`models._now()`）；业务逻辑比较时间必须用 UTC 基准（`pay._utcnow()`），**禁止用 naive 本地 `datetime.now()` 对 DB 时间做比较**（曾导致 8 小时偏差，订单幂等失效，v12 修复）

### 错误码规范
- 未配置的服务明确报错、不静默降级：403（未配置 OCR/ASR 等能力）、501（未实现）、502（微信下单失败）、503（未配置 LLM/微信支付）

## 5. 接口清单

### 认证 / 用户（`auth.py`）
- `POST /api/auth/wx-login`（code→JWT）、`POST /api/auth/login`（账号密码）、`POST /api/auth/bind`、`GET /api/users/me`

### 客户（`clients.py`）
- `GET /api/clients`（staff 列表，?segment= new/active/dormant/risk）、`GET /api/clients/{id}`、`GET /api/clients/{id}/bookings`（上课情况）、`GET /api/clients/{id}/checkins`（打卡记录）

### 体测（`assessments.py`）
- `GET/POST /api/clients/{id}/assessments`、`GET /api/assessments/latest`

### 计划 / 饮食（`plans.py` / `diets.py`）
- `GET/POST /api/clients/{id}/plans`、`POST /api/clients/{id}/plans/generate`（客户可自助，需 AI 订阅；staff 不限）
- `GET /api/exercises`（动作库）
- `GET/POST /api/clients/{id}/diets`、`POST /api/clients/{id}/diets/ai-generate`（需 AI 订阅/LLM）、`POST /api/diets/{id}/confirm`（教练一键确认）
- `POST /api/plan-requests`（学员求助教练，通知教练）

### 打卡 / 上传（`checkins.py` / `uploads.py` / `files.py`）
- `POST /api/checkins`、`GET /api/checkins/mine`、`GET /api/clients/{id}/checkins`
- `POST /api/uploads`（图片 ≤5MB）→ `GET /api/files/{filename}`（鉴权下载）

### 支付 / 订阅（`pay.py`）
- `GET /api/products`（在售；`?all=true` 仅 owner 看全部）
- `POST /api/products` / `PATCH /api/products/{id}`（仅 owner：定价/时长/上下架）
- `POST /api/orders` → `{out_trade_no, prepay_params}`（100 分钟内 pending 订单幂等复用）
- `POST /api/pay/notify`（微信回调：验签→幂等→开通/续期订阅→通知客户）
- `POST /api/orders/{id}/refund`（仅 owner，全额退款）
- `GET /api/orders/mine`、`GET /api/orders`（staff）
- `GET /api/subscriptions/mine` → `{active, plan_name, expires_at}`

### 仪表盘 / 其他
- `GET /api/dashboard/coach/overview`（会员分层/待办/客户列表）、`GET /api/dashboard/me/monthly`（月度总结）
- `POST /api/intake/text|photo`（智能录入）、`GET /api/notifications`、`GET/POST /api/custom-fields`

## 7. 关键实现说明

### 7.1 认证鉴权
- JWT（`SECRET_KEY` 签名）；`auth_lib.client_visible_to`（客户看自己/教练看名下/馆主全馆）、`require_staff`、`get_own_client`
- 生产必须配置：`SECRET_KEY`、`DATA_ENC_KEY`（敏感字段加密）、`ADMIN_PASSWORD`、`CORS` 白名单

### 7.2 AI 门禁（`ai_gate.py`）
- 两级：门店级 `AiSubscription`（旧手动通道，intake 的 voice/extract/ocr 用）+ 学员级 `ClientSubscription`（v12，diets/ai-generate 与 plans/generate 客户自助用）
- 无有效订阅 → 402 "开通 AI 会员后使用"；staff 直接放行

### 7.3 微信支付 v3（`services/wxpay.py`，无新增第三方依赖）
- 商户请求签名：RSA-SHA256，`WECHATPAY2-SHA256-RSA2048`
- 调起签名：`{appid}\n{timeStamp}\n{nonceStr}\n{package}\n`，signType=RSA
- 回调验签：平台证书验签 + 时间戳漂移 5 分钟防重放 + APIv3Key AES-256-GCM 解密 resource
- 幂等：下单复用（100 分钟）、回调重复回 SUCCESS、退款号派生（微信端天然幂等）
- 配置（环境变量，7 项）：`WXPAY_APPID / WXPAY_MCHID / WXPAY_APIV3_KEY / WXPAY_PRIVATE_KEY / WXPAY_CERT_SERIAL / WXPAY_NOTIFY_URL / WXPAY_PLATFORM_CERT（可选）`

### 7.4 通知
- 站内通知统一 `notify.py`；微信订阅消息预留调用点（模板申请后填 ID）

### 7.5 文件与隐私
- 上传落 `backend/uploads/`，**不静态挂载**，统一走 `/api/files/{filename}` 鉴权下载（按下发记录归属校验：客户看自己/教练看名下/馆主全看）
