# 域名 ICP 备案操作指南（zytzml.cn · 个人主体）

> 适用场景：域名 `zytzml.cn`（解析到香港服务器，尚未备案），目标为小程序正式上线。
> 结论前置：**备案免费，材料只要一张身份证，卡时间的只有省通管局审核（约 10~20 个工作日）**。
> 硬规则：**服务器必须在中国大陆**，香港/海外服务器没有任何变通办法备案。

---

## 0.5 大陆服务器选型（照这个买）

| 项目 | 选择 | 理由 |
|---|---|---|
| 套餐 | **45 元/月：2核 2G / 40GB SSD / 200Mbps** | 与当前香港机同配置，实测负载 CPU 1~2%、内存 30%，余量充足。40 元档只有 1G 内存偏紧不建议，50 元以上对本系统是浪费 |
| 时长 | **年付优先** | 年付折算通常比月付便宜不少；且备案后更换服务器/接入商要办「接入备案」，一次买定省事 |
| 镜像 | **Ubuntu 22.04 LTS 公共镜像（纯净版）** | `deploy/install.sh` 按 Ubuntu 22.04/24.04 编写。**不要选** WordPress / 宝塔 / 各类 AI 应用镜像 |
| 地域 | **广州** | 离柳州近、延迟低；备案归广东省通信管理局审核（管局按**服务器所在地**，不按身份证地址） |
| 供应商 | 腾讯云（与香港机同厂商） | 控制台、账号体系统一；换供应商才需要办接入备案 |

> 个人备案注意：非广东户籍的主体，广东省管局**可能**要求补充居住证明，以退回意见为准。

### 1.5 户籍地与服务器不一致（异地备案）怎么办

例：身份证是江苏苏州、服务器在广州 → 由**广东省管局**审核，属异地备案。

**结论：能办，多数情况身份证即可，不要预先折腾。**

1. **管局不卡户籍**。管局审的是「服务器所在地 + 主体真实性」。广东省管局对个人备案的主流要求就是：身份证正反面 + 人脸识别 + 本人实名手机号。
2. **万一被退回要求补居住证明**：退回意见会写明缺什么，补「江苏省居住证」或「居住登记证明」（苏服办/派出所线上可办，约 3~5 天）重新提交即可，**不是否决，是补件**。
3. **三个填表要点**：
   - 主办者性质选「个人」，证件类型/号码**按身份证如实填**（苏州），不要试图填广东地址——人脸识别和公安库核验会拆穿
   - 通信地址填实际居住地址（能收件即可）
   - 负责人手机号必须是**本人实名认证**的号码（管局会与身份证核验），别用他人号码
4. **如果确实被居住证卡住、或想一次最顺**：备选是把服务器改买**南京地域**——身份证属江苏籍=本地户籍，无异地问题。代价是江苏省管局审核偏严、周期偏长，且柳州顾客访问延迟略高。
5. **商用终局**：正式交付时备案主体应换成馆主（他的执照/身份证 + 他做小程序主体，你做开发者）。现在先用自己身份证跑通流程拿备案号，主体迁移=重新备一遍，不冲突。

## 1. 前置条件（缺一不可）

| 条件 | 说明 |
|---|---|
| 域名实名认证已通过 | 腾讯云控制台 → 域名注册 → 我的域名 → `zytzml.cn` → 实名认证。传身份证正反面，约 5 分钟提交，审核几分钟到几小时。**没通过实名认证无法提交备案** |
| 一台大陆地域轻量应用服务器 | 备案接入商就是它。买广州/上海地域入门套餐即可（本系统是 FastAPI + SQLite 单文件，2核2G 足够）。**备案期间服务器保持运行、勿到期勿关机** |
| 负责人手机号 + 邮箱 | 能收短信和邮件 |
| 身份证 | 个人主体只需身份证。广西柳州本地身份证最顺；非本地身份证可能被通管局要求补居住证明，以退回意见为准 |

## 2. 完整流程（个人主体 · 首次备案）

1. **买大陆轻量云**（广州/上海），记好实例 ID。
2. **域名实名认证**：按上表操作，等审核通过。
3. 腾讯云控制台 → 顶部搜索「**备案**」→ 开始备案 → 选择「**首次备案**」。
4. **关联资源**：选择刚买的大陆服务器实例 + 域名 `zytzml.cn`。
5. **填主体信息**：姓名、身份证号、通讯地址、手机号（个人主体）。
6. **填网站信息**：
   - **网站名称：不要填「瑜美瑜伽」**。个人备案名称不能含商号、经营性表述，会被打回。用中性名，如「**瑜伽课程预约服务**」。
   - 网站内容/服务类型：信息服务平台 / 预约服务。
   - 域名：`zytzml.cn`。
7. **上传材料 + 人脸识别**：身份证正反面 + 负责人人脸识别（全程电子化，不需要买幕布拍照）。
8. **提交** → 腾讯云**初审约 1 个工作日**（材料问题基本在这一步被打回，按退回意见改完重新提交）。
9. **工信部短信核验**：初审通过后，负责人手机会收到验证码短信，**24 小时内**登录 [beian.miit.gov.cn](https://beian.miit.gov.cn) 填写验证码 + 身份证后 6 位完成核验。**超时未验证需重新提交备案**，这是最常见的翻车点。
10. **省通信管理局审核**：服务器在广州 → 归**广东省通管局**审核（管局按服务器所在地，不按身份证地址），**约 10~20 个工作日**，期间无需操作，等通知。
11. **备案完成** → 下发备案号，格式 `粤ICP备2026XXXXXX号`，控制台可查可下载。

---

## 3. 拿到备案号之后：小程序上线还差两步

1. **小程序后台配合法域名**：开发管理 → 开发设置 → request 合法域名添加 `https://api.zytzml.cn`。
2. **小程序备案**（与域名 ICP 备案是两道，都要做）：微信公众平台 → 设置 → 基本设置 → 小程序备案，填写主体与小程序信息，微信侧审核后提交工信部，通过后才能提交小程序代码审核（上架）。
   - 域名备案主体与小程序备案主体**建议一致**；不一致官方可能要求补充说明，稳妥起见尽量用同一个主体。

---

## 4. 常见被打回 / 失败的原因

- 网站名称带商号或经营性词汇（个人备案大忌，如「瑜美瑜伽」）
- 域名实名认证未通过（或部分注册商要求实名满 3 天）
- 短信核验超过 24 小时未验证 → 整单重新提交
- 备案期间服务器关机、欠费、到期
- 网站内容描述与实际服务不符

## 5. 时间线（对照 11-09 到期日倒排）

| 时间 | 动作 |
|---|---|
| 10-23（今天） | 域名实名认证；买大陆轻量云（广州） |
| 10-24 | 提交备案 |
| 10-25 前后 | 腾讯云初审 + 完成工信部短信核验 |
| 10-25 ~ 11-15 | 广西通管局审核（10~20 个工作日，纯等待） |
| 备案号下来（预计 11 月中下旬） | ① 微信后台配 `https://api.zytzml.cn` 合法域名 ② 提交小程序备案 |
| 11-09 | 香港服务器到期：大陆机+备案若已就绪 → 切换后不续香港；未就绪 → 香港最多续 1 个月顶着 |
| 小程序备案通过后 | 提交代码审核 → 正式上架 |

> ⚠️ **顺序不能反**：备案要求域名解析指向备案的大陆服务器，所以正确顺序是
> **① 大陆机部署跑通 → ② DNS 切到大陆机 → ③ 提交备案 → ④ 等审核期间大陆机持续运行**。
> 香港机器在整个备案期间降级为「回滚备份」（DNS 改回去即可恢复），不要想着两边同时服务——域名只有一个，DNS 指向哪台就由哪台服务。

## 6. 切换大陆机时要做的事（备案通过后，可找我）

1. **数据迁移**：SQLite 数据库文件直接 `scp` 拷贝（单文件，无 schema 迁移成本）
2. **部署**：`deploy/install.sh` 在新机重跑，`backend/.env` 同步配置（注意 `WECHAT_APPID`/`WECHAT_SECRET` 用正式小程序的）
3. **证书**：certbot 对 `api.zytzml.cn` / `www.zytzml.cn` 重新签发
4. **微信后台**：request 合法域名确认指向新机 IP
5. **DNS 切换**：三条 A 记录改到大陆机 IP（改前 TTL 调低，改后观察），保留回滚预案（改回香港 IP）
6. **香港机**：确认大陆全链路正常后，到期不续费；如数据已迁走，建议跑一次导出校验再释放
