# 合规清单（PIPL 个人信息保护法对照）

> 本清单为工程自查用，不构成法律意见；正式上线前请律师复核。

| # | 要求 | 落地情况 |
|---|---|---|
| 1 | 隐私政策、用户协议公示 | `docs/privacy-policy.md`、`docs/user-agreement.md` 初稿已起草（头注：需律师审核）；小程序上架时需在应用内展示 |
| 2 | 敏感个人信息单独同意 | `consents` 表（用户/类型/时间/版本）；评估、智能录入等敏感信息入库前调用 `require_sensitive_consent` 校验，未同意返回 403 |
| 3 | 14 周岁以下未成年人监护人同意 | `clients.is_minor` + `guardian_consent` 标记；未成年人未提供监护人同意时敏感信息录入被拒绝 |
| 4 | 最小必要与权限分离 | 三角色 RBAC：客户仅见本人；教练仅见所带客户；字段级过滤（客户看不到 notes/欠费等内部字段）；越权 403 |
| 5 | 用户权利（查阅/更正/删除/注销） | `GET /api/me/data` 导出、`PUT /api/me/data` 更正、`DELETE /api/me/data` 删除敏感数据、`POST /api/me/deactivate` 注销（停用账号） |
| 6 | 数据本地化、不跨境 | 自建服务器部署于境内；AI 接口选用 DeepSeek/千问等国内服务（OpenAI 兼容接口，默认不走境外） |
| 7 | 传输与存储安全 | 生产要求 HTTPS（见部署文档）；手机号 Fernet 加密存储，密钥走环境变量 |
| 8 | 审计追溯 | `audit_logs` 表记录关键写操作（操作人/动作/对象/时间） |
| 9 | 日志脱敏 | 不记录密码、密钥、手机号明文到日志 |
| 10 | 小程序上架合规 | ICP 备案；健身类目；微信支付商户号（如收 AI 订阅费）；iOS 虚拟支付限制需单独评估 |
