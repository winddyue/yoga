## 一、服务器域名登记

### 路径

**开发管理 → 开发设置 → 服务器域名**（部分账号在「开发 → 开发管理 → 开发设置」）

点「修改」→ 管理员扫码 → 在下列三类里**各填一条**：

| 类型 | 填写内容 |
|---|---|
| request 合法域名 | `https://api.zytzml.cn` |
| uploadFile 合法域名 | `https://api.zytzml.cn` |
| downloadFile 合法域名 | `https://api.zytzml.cn` |

规则：只写域名，**不带端口、不带路径、结尾不加斜杠**；每月最多修改 5 次，别反复试。

### 前置条件与可能的报错

1. **域名必须已完成 ICP 备案**。zytzml.cn 目前解析到中国香港服务器，
   香港服务器无法备案 → 保存时大概率提示「域名未备案」而失败。
2. 证书必须是受信任 CA 签发的有效证书（TLS ≥ 1.2），自签不行。
3. 修改后约 5~10 分钟生效。

### 如果提示「域名未备案」

- **体验版**：不必强求。让顾客点小程序右上角「⋯」→ **打开调试**，即可绕过域名校验正常请求。
- **正式版**：绕不过去。要么加大陆服务器/CDN 走接入备案（10~25 个工作日），
  要么改用微信云托管/云开发（用微信自带域名，免备案）。

## 二、用户隐私保护指引

### 路径

**设置 → 服务内容声明 → 用户隐私保护指引 → 更新**

这是一份**表单**，平台会拿它和代码里实际调用的隐私接口做比对：
声明没写但代码调了 → 审核会被拒；声明写了但代码没调 → 也会被问询。
下面按本项目的实际情况逐项给填写建议（页面文案可能微调，以页面实际选项为准）。

### 1. 收集的信息（勾选）

依据代码实际调用，勾选以下几类：

| 信息类型 | 为什么 | 代码来源 |
|---|---|---|
| 微信登录信息（openid） | 免密登录与登录态续期 | `wx.login`（api.js / app.js） |
| 手机号 | 客户档案登记与联系 | 客户建档表单（手动填写） |
| 相册（读取/写入） | 体测单拍照识别、签到拍照 | `wx.chooseMedia`（intake.js、utils/checkin.js） |
| 摄像头（拍照/录像） | 同上 | 同上 |
| 健康/身体数据（身高、体重、体脂、围度、血压、伤病史等） | 体测评估、训练与饮食方案制定 | 体测记录、评估模块 |

**不要勾**（代码没用到，勾了会被问询）：位置信息、通讯录、麦克风、剪贴板、
蓝牙、微信运动步数、设备信息。

健康数据属于**敏感个人信息**，页面会要求说明"必要性与对用户权益的影响"，
按下面口径填：用于教练为客户制定训练计划与饮食方案，是本服务核心功能所必需；
不提供则无法建立体测档案与生成方案。

### 2. 第三方共享（重要，别漏）

如果启用了 AI 功能（智能录入），上传的体测单图片/文本**会发送给第三方大模型服务**
（`AI_API_URL` 配置的那家，如 DeepSeek/千问）。这一条必须在指引里写明，例如：

> 为提供「智能录入」服务，我们会将您上传的体测单图片或文本发送至第三方
> AI 服务商进行处理，处理完成后仅返回结构化结果用于生成体测记录。
> 我们不会将您的个人信息用于模型训练以外的其他用途。

未启用 AI 时可不写；但一旦启用而未声明，属于声明与实际不一致。

### 3. 信息存储地区

后端实际部署在**中国香港地区**，请如实选择/填写，不要填"境内"——
与隐私政策（`docs/privacy-policy.md`）保持一致，也避免合规风险。

### 4. 其他项

- **用户权利**：查阅、更正、删除、撤回同意、注销账号（应用内「我的」页可操作）。
- **未成年人**：14 周岁以下需监护人同意。
- **生效日期 / 联系方式**：`docs/privacy-policy.md` 里这两处仍是 `____` 占位，
  填指引前先补上（馆名已改为「瑜美瑜伽」）。
- 指引正文可直接沿用 `docs/privacy-policy.md` 的内容。

### 5. 提交后

- 指引更新需平台审核，通常 1~3 个工作日，审核通过后生效。
- 生效后才会在调用相册/相机时弹出隐私授权弹窗——代码里的
  `components/privacy` 组件已就位，用户点「同意并继续」即可正常使用拍照功能。

## 三、配置顺序建议

1. DNS 解析 → 跑 `deploy/setup-domain.sh` 拿到 HTTPS 证书（服务器侧）
2. 后台登记服务器域名（本文件第一节）
3. 后台提交用户隐私保护指引（第二节，需等审核）
4. 开发者工具上传代码 → 后台设为体验版 → 加体验成员 → 发二维码
5. 顾客首次使用：右上角「⋯」→ 打开调试（未备案期间的必要步骤）
