# 从「小程序测试号」迁移到正式小程序（发体验版必读）

> 背景：当前 `miniprogram/project.config.json` 里的 `appid` 是 `wx9044a46abff9cf68`，
> 属于**小程序测试号**。测试号后台只有"开发"相关页面，**没有"开发设置 / 版本管理 /
> 成员管理"**，因此不能上传代码、不能设体验版、不能加体验成员。
> 微信开发者工具 CLI 对测试号执行 `upload` 会打印成功但实际上传不了 —— 别再信那个日志。
>
> 要解决只有一条路：注册一个**正式小程序**，换掉 AppID。

---

## 一、注册正式小程序

1. 打开 https://mp.weixin.qq.com → 右上角「立即注册」→ 选「小程序」。
2. 填邮箱：**必须是没注册过公众号/小程序、也没绑定过个人微信的邮箱**（一个邮箱只能绑一个号）。
   - 收激活邮件 → 点链接 → 选主体类型。
3. 主体类型二选一：
   - **个人**：填姓名 + 身份证号，管理员微信扫码验证，几分钟搞定。
   - **企业/个体工商户**：营业执照 + 对公打款或微信认证（300 元/次）。
4. 注册完成后，进「设置 → 基本设置」把小程序名称改成「瑜美瑜伽」、传头像、选服务类目
   （建议「体育 → 健身」或「生活服务」）。名称如需审核一般 1–7 个工作日，重名会被打回。

**个人主体的限制（先有心理预期）**

| 能力 | 个人主体 | 企业主体 |
|------|---------|---------|
| 上传代码 / 设体验版 | 可以 | 可以 |
| 体验成员上限 | 15 人（未认证） | 90 人（认证后） |
| 微信认证 | 不支持 | 支持 |
| 微信支付 | 不支持 | 支持 |
| 正式发布上线 | 可以（类目受限） | 可以 |

本项目如果后续要接会员卡在线支付，就必须用企业主体；只做体验/内部测试，个人主体够了。

---

## 二、拿到新 AppID

登录新号 → 左侧「开发管理」→「开发设置」→ 最上方即是 **AppID（小程序 ID）**，形如 `wx` + 16 位。

同时在这一页顺便记下：**AppSecret（小程序密钥）**，第一次需要点"生成"。服务器调
`code2session` / `getuserphonenumber` 要用它（写进 `/opt/yoga/backend/.env` 的
`WECHAT_APPID` 和 `WECHAT_SECRET`，改完 `sudo systemctl restart yoga-backend`）。

---

## 三、换 AppID（两处，都要改）

### 1. 代码里

`miniprogram/project.config.json`：

```json
"appid": "wx新的AppID"
```

### 2. 微信开发者工具里

- 打开项目 → 右上角「详情」→「基本信息」→ AppID 右侧「修改」→ 填新 AppID；
- 或者：工具首页「项目 → 导入项目」，目录选 `miniprogram`，AppID 填新的，勾"不使用云服务"。

改完**关掉项目重开一次**，模拟器会重新拉一次权限配置。

---

## 四、新号是空的，这三项要重新配

正式号跟测试号数据不互通，下面三件事在新号后台重做一遍：

1. **服务器域名**：开发管理 → 开发设置 → 服务器域名 → request 合法域名填
   `https://api.zytzml.cn`（详见 `docs/wechat-mp-setup.md` 第一节）。
2. **用户隐私保护指引**：设置 → 服务内容声明 → 用户隐私保护指引 → 更新。
   勾选清单见 `docs/wechat-mp-setup.md` 第二节，抄一遍即可。
3. **类目**：设置 → 基本设置 → 服务类目，必须选（否则部分接口被禁）。

---

## 五、上传并设为体验版

1. 开发者工具 → 右上角「上传」→ 填版本号（如 `1.0.0`）与备注 → 上传。
2. 回到后台「管理 → 版本管理」→ 开发版本右侧下拉箭头 →「设为体验版」。
3. 后台「管理 → 成员管理 → 体验成员」→ 添加要体验的人的微信号（个人主体上限 15 人）。
4. 体验者用微信扫码或搜小程序名打开即可，**但必须开调试**：
   右上角「⋯」→「打开调试」→ 会自动重启小程序。
   不开调试会报 `url not in domain list`，因为 `api.zytzml.cn` 未做 ICP 备案。

---

## 六、测试期两条安全提醒

- 测试库**别放真实客户手机号**：未配置 `DATA_ENC_KEY` 时手机号是明文入库的。
- 体验版管理员账号密码不是 `admin123`，在服务器上用
  `sudo grep ADMIN_PASSWORD /opt/yoga/backend/.env` 取。

---

## 七、正式发布（体验版之后的下一步）

正式发布需要过两道备案，缺一不可：

1. **小程序备案**：后台「设置 → 基本设置 → 小程序备案」提交主体信息。
2. **域名 ICP 备案**：`api.zytzml.cn` 需要备案。
   ⚠️ 当前服务器在中国香港（43.128.26.65），**香港服务器无法做 ICP 备案**。
   要正式上线，得换成大陆服务器，或改用微信云托管 / 小程序云开发免备案方案。

在那之前，体验版 + 调试模式是唯一能用的路子。
